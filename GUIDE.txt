GESTION DES ACHATS — VERSION 1
1. Décompressez le ZIP. Hébergez index.html, manifest.json, sw.js et icon.png ensemble sur un hébergement statique HTTPS (par exemple GitHub Pages, dépôt public gratuit). Ne publiez jamais vos factures ni vos sauvegardes dans le dépôt.
2. GitHub Pages : créez un compte et un dépôt public, ajoutez les quatre fichiers à la racine, puis Settings > Pages > Deploy from a branch > main / root > Save. Ouvrez l'adresse HTTPS affichée. Cette procédure peut être plus facile sur ordinateur ; sur iPhone utilisez Safari et l'affichage bureau si nécessaire.
3. Sur iPhone, ouvrez l'adresse dans Safari, Partager > Sur l'écran d'accueil > Ajouter. Ouvrez l'icône et laissez charger une première fois avec Internet. Testez ensuite le mode avion.
4. Créez un fournisseur et un article, puis une facture. Le prix HT est saisi par emballage, la TVA en pourcentage. Le conditionnement indique le nombre de kg, litres ou pièces par emballage.
5. Comparaison : dernier prix connu de chaque fournisseur, HT ou TTC, par emballage ou unité de base. Historique : graphique HT par unité de base.
6. Import Excel : première feuille, en-têtes exacts affichés dans l'application, dates AAAA-MM-JJ ou dates Excel numériques. Une ligne par article de facture. Les factures existantes (fournisseur + numéro) sont ignorées. Vérifiez le bilan avant confirmation. Le modèle CSV est disponible dans l'application. Export XLSX : lignes d'achat, sans photos ni fiches non utilisées.
7. Sauvegarde JSON : exportez régulièrement dans Fichiers/iCloud. Elle contient les photos et toutes les fiches. La restauration remplace les données. Le stockage local est limité et peut être effacé par iOS ; photos limitées à 1,5 Mo chacune, plusieurs photos peuvent saturer le stockage.
8. Version initiale : syntaxe JavaScript vérifiée, pas de test réel sur iPhone. Import XLSX standard non chiffré, première feuille sheet1.xml uniquement ; pas de correspondance automatique des colonnes. Aucun OCR. Pas de synchronisation. Ne supprimez pas les données Safari sans sauvegarde.
